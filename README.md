# Supplier Management System Backend

This individual Web Technology and Internet assignment implements the AUCA Supplier Management System API. It stores suppliers, procurement officers, supply categories, branches, purchase orders, and delivery notes in PostgreSQL. The API is built for the required Activities A–F and is ready for manual Postman testing after the database is configured and seeded.

## Technologies

- Java 21
- Spring Boot 4.1.2
- Spring Web MVC
- Spring Data JPA / Hibernate
- PostgreSQL JDBC driver
- Maven Wrapper

The build file uses `spring-boot-starter-webmvc`, `spring-boot-starter-data-jpa`, and the PostgreSQL driver. The database schema is updated from JPA entities with `spring.jpa.hibernate.ddl-auto=update`; SQL output is enabled with `spring.jpa.show-sql=true`.

## Database setup

Clone the project and create the PostgreSQL database expected by the application:

```sql
CREATE DATABASE midterm;
```

Clone the repository:

```bash
git clone https://github.com/kevin-0703/supplier-management-system-backend.git
cd supplier-management-system-backend
```

Before running the application, update `spring.datasource.username` and `spring.datasource.password` in `src/main/resources/application.properties` to match your PostgreSQL credentials. The default database name is `midterm`; change `spring.datasource.url` there if you use another name. The schema is created/updated automatically when the application starts. Add the assignment's Step 0 seed records by calling the API save endpoints; the project does not contain automatic seed data.

## Install, build, and run

From the project root:

```bash
mvn spring-boot:run
```

The API listens at `http://localhost:8080`.

## API endpoints

All entity request bodies use direct JSON entity representations. UUIDs are generated by JPA. For CRUD entities, save returns HTTP 201 with a success message, get by ID/update/delete return HTTP 404 when the record does not exist, and successful operations return HTTP 200. `GET /all` currently returns 404 with a not-found message if the table is empty.
